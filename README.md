# 🎣 大分釣り日和情報

PythonとStreamlitを使用して、
大分県の漁港ごとの釣りやすさを表示するWebアプリ(というかサイト)です。

## 🌐 WebアプリURL
[🎣 Webアプリはこちら](https://oita-fishing-dashboard-hnynk3uwzr7gtoashct5zq.streamlit.app/)

## 使用技術
- Python
- Streamlit
- pandas
- requests

## 主な機能
- 天気取得
- 風速取得
- 降水確率表示
- おすすめ漁港表示
-満潮と干潮の詳しい情報も欲しかったですが、APIが有料のため断念🐡

-駆け出しのエンジニアではありますが、少しずつ高度なものを作れるように頑張ります🔥
