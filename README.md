PythonとStreamlitを使用して、
大分県の漁港ごとの釣りやすさを表示するWebアプリです。

[🎣 Webアプリはこちら](https://oita-fishing-dashboard-hnynk3uwzr7gtoashct5zq.streamlit.app/)

## 🐡 開発背景・工夫した点

Pythonを使用し、大分県の複数の漁港の釣り日和情報を取得するWebアプリを作成しました。

ロジックとしては、無料APIから天気情報を取得し、

* 降水確率
* 風速
* 時間帯

などをもとに独自にランク付けを行い、漁港ごとの釣りやすさを表示しています。

当初は満潮・干潮情報も実装予定でしたが、使用したいAPIが有料だったため、今回は断念しました。

また、サイトを常に最新状態に保つために定期実行を導入しました。

最初はWindowsのタスクスケジューラで実装を試みましたが、PCがスリープ状態だと実行されない問題があったため、GitHub Actionsを使用したクラウド側での定期実行へ変更しました。

これにより、PCを閉じている状態でも自動でデータ更新が行われ、常に最新の情報を公開できる構成になっています。

さらに、Streamlitを使用してWebアプリ化を行い、URLを発行することでスマホからでも閲覧可能になっています。

今回の開発では、

* Pythonによるデータ取得
* データ加工を行いCSVへの転記
* Web表示
* GitHub管理
* GitHub Actionsによる自動実行

まで一通り経験することができ、実務に近い形で開発を行うことができました。

今後は、
